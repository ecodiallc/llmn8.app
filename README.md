# Every model. One clear picture.

![image](llmn8-logo.png)

**[LLM N8](https://llmn8.app)**

## AI usage, spend and budgets — all on your device.

LLM N8 is a local-first mobile app for the AI providers you already pay for. It
brings usage, spend, budgets, model catalogs and prompt testing into one place —
without an account, a server, or telemetry.

## Features

- **One picture across providers** — Connect OpenRouter, OpenAI, Anthropic, Google Gemini, DeepSeek, Hugging Face, Cloudflare Workers AI, Novita AI, Poe, Replicate, SiliconFlow, Vercel AI Gateway, or any OpenAI-compatible server.
- **Honest sync** — Each provider shows exactly what it can do: live usage and cost sync, sync with an admin or organisation key, balance tracking only, or app-recorded completions. A dashboard never pretends a provider syncs when it does not.
- **Dashboards built from real questions** — Six templates (Overview, Trend, Budgets, Key spend, Latency & reliability, Live) and eleven widget types. Change the time range, drill into raw usage, save segments, annotate charts and export a dashboard as a PNG snapshot.
- **Budgets and alerts** — Monthly or weekly budgets for everything, one provider, one account or one model, with multiple thresholds and a projection that warns before the period ends. A scheduled daily digest summarises spend.
- **Models, pricing and comparison** — Browse each provider's catalog, compare price, context and capabilities side by side, and run the same prompts across several models as a batch.
- **Prompts and chat** — Keep a versioned prompt library, then chat against any connected model with streaming answers and a live token and cost meter.
- **Bring your own history** — Import JSON backups or CSV exports with column mapping; export plain or passphrase-encrypted JSON; reconcile provider-reported cost against local records.
- **Private by design** — No account, no ads, no third-party analytics, and no server of ours. Your usage, keys and dashboards stay on your device.
- **Personalise it** — 23 interface languages, light and dark themes, and optional biometric app lock.

## Platforms

- iOS and Android
- iPad support enabled
- Works offline; provider sync and chat need a network connection to the provider

## Privacy

- No account system
- No telemetry or third-party analytics
- No advertising
- No data collection
- Usage history, dashboards, budgets, prompts and chat history stay in a local database on your device
- API keys are stored in the operating system's keychain
- Network activity is limited to the AI providers you configure
